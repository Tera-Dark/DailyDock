# DailyDock 全面设计与交互重做验收记录

日期：2026-10-31。适用当前 `src/` 和 `extension/build/`。

## 设计依据和目标

采用用户的 [ChatGPT-Inspired UI Skill v1.1.0](https://github.com/Tera-Dark/personal-agent-skills/blob/main/02_design/chatgpt-inspired-ui/SKILL.md) 及其 token / review references。产品定位为日常任务工作空间，核心动作是记录、安排、完成、找回。桌面以弱化侧栏加内容区为骨架，窄屏使用文字导航抽屉；中等信息密度，最小目标宽度 360px，键盘和触控均有可见入口。

使用原创 DailyDock 品牌、中性色、系统字体和 Lucide 图标。已完整替换活动前端中的纸纹、木框、粉彩、胶带与装饰性英文副标题；内容、选择状态、日期提醒及当前主要操作承担视觉层级。语义变量同时覆盖浅色和深色。提示、编辑、全局搜索和确认对话框都有明确职责。

## 操作变化

- 默认进入「今天」，集中记录区、常用入口、待办及可展开的已完成事项，避免在多个模块之间来回添加。
- 快速记录明确选择待办、常用入口、网站签到三种用途；输入网址不会默默改变选择的用途。编辑保存后清空记录区，取消编辑保留原输入。
- 日期和时间始终在编辑器中可见；今天、明天、无日期快捷设置，提醒开关与环境说明相邻，低频分类和网址按需展开。
- 全局搜索覆盖任务、便签、网站和常用入口，提供按钮、Ctrl/Cmd+K 和 /，并支持 Esc。局部分类筛选仍保留。
- 删除先进入回收站，提示中可撤销；全部任务提供显式选择模式和批量完成、批量移除。
- 日历与主列表共用 TaskList，按选择日期记录完成；可筛掉网站，只查看待办便签。切月时选中日期随之更新。
- 便签采用中性网格，保留图钉拖动、键盘排序、前后移动、一键整理和日期提示。
- 签到和常用入口采用应用图标网格；内置图标来自本地资源，其他站点使用站点自身 favicon，失败时回退首字母。
- 侧栏按日程、内容、管理分组；桌面折叠，手机文字抽屉。视图 hash 支持刷新和前进后退。
- 弹窗与管理页共用记录规则和编辑器，保留当前网页主动收录。

## 验证证据

### 自动检查

`npm run check` 运行 6 个测试文件、22 项测试，以及 TypeScript 与 Vite 生产构建。

覆盖：周期和完成规则、旧备份兼容、回收站与排序、网页/扩展存储、当前标签页读取、推荐、日期提醒去重。新增直接加载扩展后台源码的测试，检查单次日期调度及已完成、删除、未来、过去事项不误发。修复无日期事项完成后从当天日历消失、无法撤销的问题，并增加回归测试。

`vitest.config.ts` 限定 `src/**/*.test.ts`，不会把 `.local-backup/` 的历史测试算入结果。历史 `tests/smoke.mjs` 不作为当前 UI 验收依据。

### 实际配色检查

按当前 CSS token 计算对比度（比值）：浅色正文/白底 16.11、浅色辅助字/浅灰底 5.38；深色正文/深底 14.51、深色辅助字/灰底 6.97；浅色输入边界/白底 3.68、深色输入边界/表面 4.76；浅色焦点/白底 5.17、深色焦点/深底 8.84。修复深色主要按钮 hover 背景被次级按钮覆盖、文字对比不足的问题。以上是指定 token 配对检查，不是完整 WCAG 认证。

## 数据与运行约束

原存储键、任务字段、历史记录、排序和 JSON 任务备份兼容，Web / 扩展各自存储。构建保留在原 `extension/build/`，扩展仍从原 `extension/` 加载；不会改变用户原站点的数据源。仓库不包含用户本地数据和本机备份。

网页版提醒仍受页面打开、通知权限、后台限速和设备休眠影响。扩展真实安装后的当前网页收录、系统通知、通知音和系统交互本轮未在 Chrome/Edge 中端到端验证；仅对应适配器/后台测试通过。真实触屏、软键盘、辅助阅读器和 OS 200% 缩放未实测；CSS 已提供响应式、可访问名称、键盘焦点和减少动画支持，不宣称等同实际设备认证。大数据量性能未做基准测试。

## 交付检查

源码与所有活动页面使用同一套语义 token 和交互组件。生产构建、测试、浏览器证据与使用说明相符。README 已同步新入口、快捷键、记录用途、日历、批量管理、数据空间及运行限制。旧实现只作为历史文件保留，当前 HTML 指向新构建。
