# DailyDock

一个纯本地的日常工作空间。集中管理待办、便签、日历、网站签到和常用入口，提供网页版与 Chrome / Edge 扩展版。

## 开始使用

Windows 双击 `启动 DailyDock.bat`，保持命令窗口打开，访问 [http://localhost:8765/](http://localhost:8765/)。也可以在项目目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

本地交付目录可能已包含 `extension/build/` 构建产物；从 GitHub 克隆或下载源码后，请先安装 Node.js 22 并在项目目录执行 `npm ci` 和 `npm run build`，生成该目录后再启动网页或加载扩展。构建后的网页可直接使用静态服务，无需运行 Node 服务。静态服务需保持 `index.html` 和 `extension/` 的相对路径。请沿用原来的浏览器与地址：`localhost`、`127.0.0.1`、不同端口、不同浏览器和扩展的数据空间相互独立。

安装扩展：打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，启用开发者模式，加载本项目的 `extension/` 目录。更新本地构建后，点击扩展管理页的「重新加载」，再重新打开弹窗和管理页。

## 每天的使用流程

默认进入「今天」，查看未完成事项、今日进度和本地推荐入口；完成的事项收在「已完成」中，可以展开撤销完成。点击事项名称即可编辑。日期已过而未完成的单次事项会显示「已逾期」。

「快速记录」提供三个明确的用途：

- **待办**：输入一件事，回车保存为不重复事项；含网址的文字也会按待办原样记录。
- **常用入口**：粘贴网址，或输入 `名称 https://网址`，保存为不参与签到和提醒的常用网站。
- **网站签到**：输入网站名称和网址，保存为每天重复的签到事项。

点击输入区的日期图标，可继续设置日期和提醒；保存成功后原输入清空，取消编辑会保留原输入。侧栏的「新建事项」可直接打开完整编辑器。网页版和扩展弹窗使用相同的记录规则。

## 查找和管理

- **搜索**：侧栏搜索、右上角搜索按钮、`Ctrl/Cmd + K` 或非输入状态下的 `/`，打开全局搜索。匹配名称、分类和网址。选择待办会打开编辑器，选择常用入口会打开网站。`Esc` 关闭搜索和编辑窗口。
- **全部任务**：搜索并按全部、待完成、已完成筛选；「选择」进入批量操作，可完成或移除所选事项。可一次选择当前筛选结果。
- **回收站**：删除后先移入回收站，短暂提示支持撤销；回收站中可恢复，永久删除需确认。恢复常用入口时会检查重复网址。
- **导航**：桌面侧栏支持图标模式和文字模式；窄屏使用带文字的抽屉导航。页面地址的 hash 保存当前视图，刷新与浏览器前进后退可返回对应页面。

## 便签与日历

「便利贴」集中展示无网址事项。点击图钉拖动排序，或使用前移、后移按钮。图钉支持键盘：空格拿起，方向键移动，再按空格放下，`Esc` 取消。一键整理会优先未完成事项，再按创建时间排列。

点击便签的日期入口或编辑按钮，可设置日期、时间、每天或每周重复，以及到点提醒。日期有「今天」「明天」「无日期」快捷选择。提醒开启后必须设置时间；单次提醒也必须设置日期，开启时会自动补今天。

「日历」按月显示事项数量，可筛选全部事项或仅待办便签，选择日期后查看明细、添加、编辑、完成或移除事项。添加会预填所选日期。每天和每周事项按周期显示，创建之前的日期不会凭空出现未完成历史；旧的完成记录仍可查看。无日期单次事项显示在今天，完成后仍可在当天撤销。已指定日期的事项留在原计划日期，逾期未完成的同时出现在「今天」。周期事项勾选完成会记录选中日期，而不是当前日期。

## 常用入口和签到

「常用入口」支持一行收录、分类搜索、置顶、常用优先和最近打开。新入口会尝试沿用本地已有同域名分类。使用记录只统计通过 DailyDock 主动打开的入口，不读取浏览器历史；使用次数、最近时间和三小时粒度的时段计数保存在本机，并包含在 JSON 备份中。

「今天」可显示最多四个置顶或使用过的入口，结合频率、近期和时段排序。在「设置 → 常用推荐」可关闭显示。

扩展弹窗的「收录当前网页」在你点击时，通过 `activeTab` 读取当前页面并保存；名称、分类之后可修改。内部页面及无法读取的页面会提示失败。网页版不能读取其他标签页，可手动粘贴网址。

「网站签到」提供网站网格和分类筛选。打开网站不会自动标记签到成功，完成后请自己勾选。首次使用加入 Linux DO、昆仑 API、AnyRouter 和 X666，删除后不会自动再加入。同一网址可以分别作为常用入口与签到事项存在，各自列表内会阻止重复新增。站点以应用图标网格显示：内置站点使用本地图标，其余站点直接请求网站根目录的 favicon；获取失败时显示名称首字母。访问图标时会向对应网站发出请求，不使用第三方图标服务。

## 提醒与测试

在编辑器选择日期和时间，开启「到点提醒」。已完成和回收站内容不会提醒，指定日期的单次提醒只在那天触发，逾期后不会每天重复提醒。

网页版需要页面保持打开，并允许桌面通知；短暂延迟可补偿最近两分钟，提醒去重保存在本地。点击一次「设置 → 提醒与测试 → 试听提醒音」可激活声音，并可体验 10 秒后的测试提醒。浏览器限制、页面关闭、休眠或关机都可能导致错过提醒，不能代替系统闹钟。

扩展使用 `chrome.alarms` 和系统通知，支持通知中的「10 分钟后提醒」和打开管理页；浏览器需运行且系统需允许通知。扩展实际提醒采用系统通知音，试听仅在当前页面播放。

## 本地数据与备份

网页使用同源 localStorage，扩展使用 `chrome.storage.local`。任务、便签顺序、完成记录、回收站和常用入口记录兼容既有存储键与 JSON 备份。清理浏览器数据、卸载扩展或换浏览器会影响数据，请定期在「设置 → 本地数据」导出备份。

导入需要确认覆盖，最大 20 MB、3000 项；无效文件不替换现有数据。JSON 备份导出内容为任务及入口数据，主题、侧栏及推荐开关等偏好保存在当前环境中。不同数据空间不会自动同步，可通过导入导出迁移。无 Web Locks 时，跨页面同时修改仍可能存在竞争。

## 设计与开发

遵循用户的 [ChatGPT-Inspired UI Skill](https://github.com/Tera-Dark/personal-agent-skills/blob/main/02_design/chatgpt-inspired-ui/SKILL.md)：内容优先、中性配色、克制控件、按需展开复杂选项。DailyDock 保持独立品牌。使用系统字体、Lucide 图标、统一主题变量与焦点状态，支持减少动画偏好。

技术栈为 React、TypeScript、Vite、Radix UI 和 dnd-kit。网页与扩展共享组件和模型。`src/` 是新版源码，`extension/build/` 是运行产物；`extension/app.js`、`extension/style.css` 和 `tests/smoke.mjs` 为历史版本保留，不是新版入口或主验证流程。本机可能存在的 `.local-backup/` 被 Git 忽略，不属于仓库交付物。

```text
src/App.tsx              页面组合、导航和本地操作
src/components/          记录、清单、便签、日历、编辑、搜索、设置
src/model.ts             日期、周期、备份和推荐规则
src/storage.ts           网页与扩展存储适配
src/reminders.ts         网页提醒
extension/background.js  扩展后台提醒
extension/build/         构建后的共享资源
```

开发需要 Node.js。在项目目录执行：

```powershell
npm ci
npm run check
```

`npm run check` 运行自动测试、TypeScript 检查和生产构建。测试范围限于 `src/**/*.test.ts`，避免误运行本地历史备份。UI 回归与具体限制见 [审查记录](docs/UI-UX-REVIEW.md)。
